# Документация

Приложение работает на обычных HTML, CSS и JavaScript. Для запуска достаточно открыть `index.html` в современном браузере.

## Возможности

- Пересчёт веса: кг, г, фунты и унции.
- Пересчёт роста: см, м, дюймы и футы.
- Пересчёт температуры: °C и °F.
- Изменение направления пересчёта кнопкой со стрелками.

Все расчёты выполняются в браузере; данные никуда не отправляются.
