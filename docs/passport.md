# Паспорт проекта

**Название:** Лапки — конвертер единиц для питомцев
**Цель:** помочь владельцам питомцев быстро переводить вес, рост и температуру между единицами измерения.
**Целевая аудитория:** владельцы кошек и собак.
**Стек:** HTML, CSS, JavaScript (без фреймворков).

## Основные сценарии
1. Пользователь выбирает категорию (вес, рост, температура), вводит значение и видит результат.
2. Пользователь меняет единицы местами кнопкой «поменять».

## Структура
- index.html — главная страница
- css/styles.css — стили
- js/app.js — логика пересчёта и валидации
- docs/ — документация
