# Конвертер единиц для питомцев

Небольшое приложение для пересчёта веса, роста и температуры при уходе за питомцем. Введите значение, выберите единицы и при необходимости поменяйте направление конвертации.

## Запуск

Откройте `index.html` в браузере. Сборка, сервер и установка зависимостей не нужны.

## Структура

- `index.html` — разметка приложения.
- `css/styles.css` — адаптивные стили.
- `js/app.js` — категории, единицы и расчёты.
- `docs/README.md` — краткая документация.
